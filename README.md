## 5. Scenario-Based Demo & Practice Questions

### Question 1
In Oracle Digital Assistant (ODA), what component evaluates user input at the parent level to determine which child skill should handle the user request?

A) Skill BotML Interpreter
B) Digital Assistant Routing Engine / System.Intent
C) Webhook Channel Listener
D) Entity Value Extractor

- **Correct Answer**: `B) Digital Assistant Routing Engine / System.Intent`
- **Technical Explanation**: The Digital Assistant router evaluates incoming user utterances using natural language models to identify candidate skills and routes the interaction to the appropriate child skill.

---

### Question 2
Which entity type in Oracle Digital Assistant is best suited for collecting multiple interrelated values (e.g., origin, destination, departure date, and seating class for a flight booking) in an organic order?

A) Simple Value List Entity
B) Regular Expression Entity
C) Composite Bag Entity
D) System.String Entity

- **Correct Answer**: `C) Composite Bag Entity`
- **Technical Explanation**: Composite Bag Entities group multiple related entities, manage prompt logic, validation, and disambiguation, and allow users to provide attributes in any arbitrary sequence.
